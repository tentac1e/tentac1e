# Гид по базилику

Одностраничный сайт о выращивании базилика: от выбора сорта и посева до сбора урожая, заготовок и лечения.

## Что внутри

- **Главные правила** — восемь вещей, от которых зависит урожай.
- **Сорта** — 14 сортов и видов с фильтром (для песто, подоконника, фиолетовые, азиатская кухня, чай, декоративные).
- **Где растить** — подоконник, балкон, открытый грунт, теплица, гидропоника.
- **Календарь посадки** — расчёт сроков по дате последнего заморозка (грядка/теплица) или по дате посева (дом).
- **Посев и рассада**, **свет, полив, тепло и почва**.
- **Удобрения** — роль каждого элемента (N, P, K, Ca, Mg, S, Fe, Mn, Zn, B, Cu, Mo), признаки нехватки и избытка, питание по семи стадиям роста, таблица удобрений, калькулятор раствора, EC и pH для гидропоники, мифы о подкормках.
- **Прищипывание** — теория, схемы и интерактивный тренажёр.
- **Сбор и хранение**, рецепт песто, **размножение черенками**.
- **Диагностика** — 21 симптом с причинами и лечением, справочник болезней и вредителей.
- **Частые вопросы** и **чек-лист сезона** (отметки сохраняются в браузере).

Светлая и тёмная темы, адаптивная вёрстка, учёт `prefers-reduced-motion`.

## Запуск

Сборка не нужна: откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

```
index.html          разметка и текстовый контент
assets/css/style.css стили и цветовые токены обеих тем
assets/js/app.js    данные (сорта, элементы, стадии, симптомы) и интерактив
```

Дозы и сроки — ориентиры для средних условий; инструкция производителя удобрения всегда в приоритете.
